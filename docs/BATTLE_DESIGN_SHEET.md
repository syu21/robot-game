最終更新日: 2026-04-07

## 1. 設計目的
- 短時間で1周できるテンポ
- 初見でも理解しやすい結果画面
- 研究余地は残すが前面情報は最小化

## 2. 戦闘テンポ
- 基本: 1出撃1戦
- 例外: 特定環境で連戦あり
- 1戦の上限: 8ターン
- 目標ターン帯: 3〜5ターン
- 第4層は上限を変えず、通常敵から `layer_3` 固定ボス級を超える強度にする
  - チュートリアル終了後の本番帯として、全体火力と耐久を一段引き上げる
  - そのうえで敵の役割差で実質ターン数を分岐させる
  - forge: やや長期戦
  - haze: MISSで伸びやすい
  - burst: 短期高刺激
- 第5層も上限は変えず、4層よりさらに高圧な終盤帯として勝ち方の軸を複数化する
  - labyrinth: 安定して抜けるか
  - pinnacle: 最速で抜けるか
  - omega: 何を捨てて何を残すか

## 3. 勝敗体験
- 勝利時: 戦利品カードを最短で確認
- 敗北時: 理由が分かるログを残し再挑戦導線を明示
- 重要: 通常戦は静か、ボス撃破時のみ演出を強める
- 第4層の役割は「背水一強をナーフではなく相性分化で崩すこと」
- 耐久 / 命中 / 爆発 / 安定にそれぞれ勝ち場所を作る

## 4. 戦利品UI方針
前面表示は以下のみ:
- 獲得コイン
- ドロップ結果（なしの場合は `戦利品なし`）
- 進化コア保証やボス報酬の短い結果表示
- `もう一度出撃` は最重要CTAとしてスマホ初期表示に入りやすい位置へ置く
- 敵情報や詳細ログは再出撃より後ろへ退避し、必要時だけ開く

前面から外す情報:
- 内部補正係数
- 出現率/ドロップ率の数式寄り表示
- 構成メモ等の分析項目

## 4.1 戦闘演出補足
- ダメージ数字はスマホで読める大きさを優先し、`HIT / CRIT / MISS / BLOCK` の違いが一目で分かるようにする
- 戦闘アニメ再生中は結果の `WIN / LOSE` を先見せしない。ネタバレを抑え、スキップ時だけ即結果へ進める

## 5. ボス戦方針
- 出現率 0.5% を基準
- 固定ボスは層進行に紐づけ
- 固定ボス/エリアボス報酬は DECOR 中心
- NPCボスは進化コア報酬あり
- SYSTEM投稿はボス撃破時のみ
- 第4層は 3サブエリア + 最終試験で型の理解を学ばせる
- 第5層は「型を誇る層」として、週環境 / 記録 / 展示へ接続する前提で設計する
