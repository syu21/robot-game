# モジュール研究システム Phase 1-2

## 基本思想

モジュールは完成品を集めるコンテンツではない。合成・継承・変化を繰り返し、その由来を研究し、結果を他者と語る研究対象である。強さの最適解より、予想・発見・系譜・共有を優先する。

## Phase 1: モジュール系譜

- 合成成功時に `module_fusion_records` へ結果モジュールの研究記録を保存する。
- 合成素材は `module_fusion_inputs` へ投入順、表示名、世代、主系統、表示用snapshotとして保存する。
- 素材モジュールが `consumed` になっても、研究記録は削除しない。
- 世代は既存合成結果の `generation` / `synthesis_generation` を記録するだけで、新しい計算式を導入しない。
- 由来は既存 `synthesis_family` から表示する。通常カードでは長大化を避け、詳細の系譜画面で履歴を追う。
- `/modules/<module_id>/lineage` で本人所有モジュールの縦型研究タイムラインを表示する。
- 旧モジュールで完全履歴がない場合は推測せず、`旧研究記録のため、一部データ未観測` と表示する。

## Phase 2: 研究記録

- `/modules/research` で自分の合成実験を一覧表示する。
- 合成実験数は正常に作成された `module_fusion_records` 件数を正本にする。
- 観測済み系統は、自分の合成結果として生成された主系統だけを数える。
- 最高世代は、所持中か消費済みかを問わず、自分が生成した結果の最大世代を使う。
- 一覧には投入素材、結果、世代、主系統、公開ステータス、作戦特性、向いている戦いを表示する。
- 初めて生成した主系統には `初観測`、過去最高世代を更新した結果には `自己最高世代更新` を表示する。
- 系統フィルター、新しい順、古い順、世代が高い順、20件単位のページングを持つ。

## Phase 3: 研究共有

- `/modules/research` の正常な合成記録から、全体会議室 `global_room` へ研究成果を共有できる。
- 共有投稿は `chat_messages` の1件として作成し、並び順、連投CT、削除、直近100件、自動更新は既存会議室仕様を使う。
- 構造化された公開情報は `module_research_shares` に保存する。
- 共有時点のsnapshotを保存し、元モジュールの消費、再合成、名前変更、inventory状態の変化では表示内容を変えない。
- 共有可能なのは本人の `provenance_quality = 'full'` かつ投入素材snapshotを持つ `module_fusion_records` だけ。
- validation失敗、legacy、壊れた記録、存在しない記録、他人の記録は共有不可。
- 共有は見栄、発見、会話、記録のための機能であり、ゲーム内性能や報酬は変化しない。
- 共有カードは会議室上では結果名、系統、世代、素材概要、ひとことだけを小さく表示し、詳細は公開snapshotページで確認する。

## 非目標

- レシピ公開
- 確率公開
- 最強レシピ
- 自動合成
- 性能に影響する共有
- 世界初
- 系統回帰自動判定
- 性能変更
- 報酬追加
- 戦闘ボーナス

## 表示しない情報

- 合成確率
- 系統別内部重み
- 継承率
- 隠し値
- 内部乱数
- score
- weight
- probability
- seed

UIは「何を入れたか」「何ができたか」「どの系譜を通ったか」だけを事実として表示する。
