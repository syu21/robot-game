# パーツ個体ステータス計算仕様

最終更新日: 2026-08-21

## 1. 内部キーと表示
- 内部: `hp`, `atk`, `def`, `spd`, `acc`, `cri`
- UI表示: `耐久`, `攻撃`, `防御`, `素早さ`, `命中`, `会心`
- プレイヤー向け表示は内部値を `100倍` してカンマ区切りで表示する
- DB、戦闘計算、ドロップ、強化、進化、audit payload は従来の内部値を使う
- `+値`、レベル、ターン、コイン、確率、CT、所持数は倍率表示の対象外

## 2. レアリティ基礎値
- `N=12`
- `R=18`
- `SR=26`
- `SSR=36`
- `UR=48`
- 虫シリーズRも通常Rと同じ `R=18`
- 虫シリーズ専用の基礎値補正は持たず、差別化は個体重み傾向とシリーズ効果で行う

## 3. 部位別重み
- HEAD: 耐久・防御寄り
- RIGHT_ARM: 攻撃・会心寄り
- LEFT_ARM: 命中・防御寄り
- LEGS: 素早さ寄り

## 4. 個体差生成
- ノイズ幅: `±0.08`
- 最小値: `0.01`
- 正規化後、`w_hp..w_cri` として保存
- 同じマスタ、同じレアリティ、同じ `plus` でも `w_*` が異なれば6ステは異なる
- `/parts` では「同名パーツでも個体性能に差があります。」と補足し、同名個体の比較を促す

## 5. plus計算
- 耐久: `round(2 * 1.35^plus)`
- その他: `round(1 * 1.45^plus)`
- 追加配分:
  - `bonus_stat = floor(plus * 6 * (w_stat / w_sum))`
  - 上限: `plus * 2`
- 強化上限:
  - N: 常に +5
  - R: 通常 +5、第4層到達後（`max_unlocked_layer >= 4`）は +7
  - SR以上: 今回は変更なし
- R+10以上は現行の指数式では伸びが強すぎるため採用しない

## 6. 進化時の挙動
- N→Rでも `plus` は維持
- 個体差重み `w_*` は維持
- 再抽選はしない
- N+5 -> R+5 後、第4層到達済みなら R+7 まで追加強化できる
- 虫シリーズNも、対応する虫Rマスタが公開条件を満たす場合は N→R 進化できる
- 虫Rは初期公開時点では `release_flags.insect_r_parts` 管理で、入手経路は進化合成のみ

## 7. テスト観点
- 同一入力で決定的に同一結果
- 同名 / 同レア / 同plusでも、個体重みが異なれば6ステの少なくとも1つが変わる
- plus上昇で総合性能が単調増加
- 進化前後で `plus/w_*` 一致
- 表示値を100倍しても内部値、ソート順、audit値が変わらない

## 8. パーツ機構特性
- v1詳細は `docs/PART_MECHANISM_TRAIT_SPEC.md`。
- 正本は `robot_parts.mechanism_trait_key` で、`part_instances` へはコピーしない。
- Nでは非発動、R以上で発動する。進化時も `plus` と `w_*` は従来通り維持する。
- 機構特性は戦闘時補正であり、通常のパーツ総合性能、思想、シリーズ効果の計算には加算しない。
