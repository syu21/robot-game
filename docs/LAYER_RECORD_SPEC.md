# 層別攻略記録仕様

## 第6層 攻略記録・研究文化 v1

目的は、第6層を「到達して終わり」ではなく、攻略記録として見返せる状態にすること。

## 集計元

- `audit.explore.end`
- `audit.boss.defeat`

新規DBテーブルは追加しない。既存auditを正本にする。

## 第6層通常戦記録

対象エリア:

- `layer_6_rebuild`
- `layer_6_core`

除外:

- `result.is_area_boss=true`
- boss payload がある探索終了ログ
- 管理者
- テストユーザー
- `analytics_excluded=1`
- banned user

二重排除:

1. `request_id`
2. `result.battle_id` または `battle_id`
3. `world_events_log.id`

## 記録種別

### 最短攻略

- 条件: 第6層通常戦に勝利
- 指標: `result.turns`
- 並び順: ターン昇順、達成時刻昇順、残HP率降順
- 表示: `最短攻略 3ターン`

### 安定攻略

- 条件: 今週の第6層通常戦5回以上
- 指標: 勝率
- 並び順: 勝率降順、出撃数降順、平均残HP率降順、達成時刻昇順
- 表示: `安定攻略 80%`

### 研究熱

- 条件: 今週の第6層通常戦出撃
- 指標: 出撃回数
- 並び順: 出撃回数降順、勝利数降順、最終出撃時刻昇順
- 表示: `第6層研究 42回`

### 最終試験

- 条件: `audit.boss.defeat` かつ `area_key=layer_6_final`
- v1表示: 初撃破者、機体、思想
- 最短ボス撃破は、turn情報の公平性を確認してから拡張する。

## UI

- `/records`: `第6層研究記録` を追加し、各カテゴリ上位3件のみ表示する。
- `/ranking?metric=layer6_research`: 今週の第6層研究ランキングを表示する。
- `/home`: 既存ランキング領域に `第6層研究速報` を短く表示する。NEXT ACTIONより上には出さない。
- `/admin/metrics`: 第6層到達者、通常戦出撃、勝率、平均ターン、ボス遭遇/撃破、記録掲載者を表示する。

## 非目標

- 第7層公開
- 戦闘バランス変更
- 新規報酬
- 新規通貨
- 通常勝利ごとの世界ログ投稿
- 記録専用テーブル
