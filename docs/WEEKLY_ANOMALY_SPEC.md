# 週替わり挑戦機《異常個体》v1

## 目的

縦方向の新層を追加せず、育成済みの機体を週替わりの一人用挑戦相手へぶつける。

主報酬は記録、解析率、級別ランキング、世界ログ。戦力インフレ報酬は配らない。

## UX

- ホーム下段に `WEEKLY ANOMALY` の短い導線を表示する。
- `/anomaly` で今週の個体、観測メモ、自分の級、自分の最高解析、級別ランキングを確認する。
- 挑戦は最大8ターン。撃破のみ `clear`、時間切れ判定勝ちは解析未完了扱い。
- 結果画面では解析率、残HP、ターンログ、初回撃破報酬、自己ベスト更新を表示する。
- `/anomaly/rankings` で `観測級 / 実戦級 / 深層級` のランキングを分けて見る。

## バックエンド

- release flag は `anomaly`。初期状態は非公開で、管理者だけ確認可能。
- 週キーはJST基準のISO週。再起動しても同じ週は同じ個体を生成する。
- 個体テンプレートは以下4系統。
  - `VEIL RUNNER`: 高速異常機。命中と安定を試す。
  - `GRAVEMASS`: 超重装異常機。火力と会心を試す。
  - `REDLINE`: 臨界暴走機。速攻と耐久判断を試す。
  - `PARADOX`: 位相不安定機。安定、耐久、上振れ対応を試す。
- 到達層で級を決める。
  - 1-2層: `observe` / 観測級
  - 3-4層: `field` / 実戦級
  - 5層以上: `deep` / 深層級
- 通常ユーザーは初回3出撃後に参加可能。管理者は確認用に制限なし。
- 既存 `run_champion_battle` を再利用する。専用戦闘エンジンは追加しない。

## 報酬

- 週・級ごとの初回撃破で小額コインのみ付与する。
- `anomaly_weekly_rewards` の一意制約で二重取得を防ぐ。
- 専用パーツ、新通貨、ランキング報酬、強力な限定装備は追加しない。

## データ構造

- `weekly_anomaly_cycles`
  - 週次個体、テンプレート、seed、開始/終了時刻を保存する。
- `anomaly_attempts`
  - 挑戦結果、解析率、残HP、ターン、payload、request_idを保存する。
- `anomaly_weekly_rewards`
  - 週・ユーザー・級ごとの初回撃破報酬を保存する。

## Audit / 世界ログ

- `audit.anomaly.cycle.create`
- `audit.anomaly.view`
- `audit.anomaly.attempt`
- `audit.anomaly.best`
- `ANOMALY_APPEARED`
- `ANOMALY_CLASS_FIRST_CLEAR`
- `ANOMALY_FASTEST_RECORD`

## 今日の研究指令

公開済み、かつ参加可能なユーザーだけ `異常反応観測` が候補に入る。

条件は `異常個体へ1回挑戦`。撃破は要求しない。

## 受け入れ条件

- 同じ週なら同じ異常個体が生成される。
- 週が変わると個体が更新される。
- release flag 非公開時は一般ユーザー不可、管理者のみ確認可能。
- 初回3出撃未満の一般ユーザーには表示・挑戦させない。
- 同一 `submission_id` の二重POSTで挑戦記録と報酬が二重作成されない。
- 撃破報酬は週・級ごとに1回だけ。
- ランキングは級別に分かれ、管理者・テスト・集計除外ユーザーを除外する。
- 今日の研究指令は対象ユーザーのみ異常個体挑戦で進む。
