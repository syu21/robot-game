# 廃品市場・コイン経済仕様

## 目的
- 余剰Nパーツを `coins` に戻し、日課として市場を見る理由を作る。
- 足りない部位を少しだけ補える救済を置く。
- Rの価値、進化コアの価値、本編探索の主役性は壊さない。

## 公開制御
- `release_flags.market` を使う。
- 初期状態は `admin_only`。
- `public` になるまでは `/market` 導線も直アクセスも管理者のみ。
- `/admin/release` では `廃品市場` と表示する。

## 通貨
- 本編探索、市場、パーツ売却、実験室レースはすべて `coins`。
- `lab_coin` は既存互換と一回限りの `coins` 変換用に残すが、新規獲得・消費には使わない。
- 実験室交換所は景品未整備のため非公開。通常ユーザーの `/lab/race/prizes` は404。

## 探索経済
- 直接コインは探索収益の主柱として維持し、初期値はTier1で16コイン前後。
- パーツドロップはNのみ。基本確率70%に、自動売却導入後の倍率0.85を掛ける。
- 自動売却収入は総収入の20から30%程度を目標にする。
- Rは探索で直接落とさず、進化コア経由を維持する。

## 市場入荷
- 6枠固定: `head / right_arm / left_arm / legs / free_1 / free_2`
- 固定4枠はN。
- 自由2枠は `N 92% / N+1 7% / R 1%`。
- 価格帯:
  - N: 40から48
  - N+1: 80から120
  - R: 600から900

## 売却
- N: `10`
- R: `25`
- 装備中は売却不可。
- 所持上限超過の新規ドロップは同じ基準で自動売却される。
- 売却・購入・再入荷は履歴テーブルと監査ログに残す。
- 旧 `overflow` は `tools/cleanup_overflow_parts.py` で一括売却できる。

## パーツ所持枠拡張
- 初期上限は `users.part_inventory_limit = 60`。
- 廃品市場で `coins` を消費し、+10単位で最大120まで拡張できる。
- 価格:
  - 60 -> 70: 400
  - 70 -> 80: 800
  - 80 -> 90: 1400
  - 90 -> 100: 2200
  - 100 -> 110: 3400
  - 110 -> 120: 5000
- 所持枠判定は `part_inventory_limit` を使う。
- 旧 `overflow` 保管は維持し、拡張しても自動移動しない。

## 再入荷
- 1回目: 0
- 2回目: 100
- 3回目: 200
- 4回目: 400
- 5回目以降: 800

## R強化補助
- 従来の `R + 同名R素材2 -> +1` は維持。
- 追加で `R + 対応N素材2 -> 補助50`。
- 補助100到達で `+1`。N4個でR+1相当。
- 補助値は `part_instances.r_assist_points` に保持する。

## UI
- ページ名は `廃品市場`。
- ヘッダーに所持コインと次回更新時刻を出す。
- 今日の入荷は6カード。
- 1枠を `今日の掘り出し物` として強調できる。
- 売却は左に候補、右に選択中件数・合計コイン・選択名のまとめパネルを置く。
